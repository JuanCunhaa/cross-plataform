# Aula 02 — Iniciando o Projeto Flutter

Sistema de Marcação de Consultas: estrutura inicial do app Flutter.

## Estrutura

```
lib/
├── main.dart                 → inicia o app
└── src/
    ├── components/           → widgets reutilizáveis (próxima aula)
    ├── screens/              → HomeScreen
    ├── styles/               → AppColors
    └── models/               → Consulta, Medico, Paciente...
```
