# Aula 01 — Introdução ao Flutter e tipagem em Dart

Base lógica em Dart para o futuro Sistema de Marcação de Consultas em Flutter.

## Estrutura

```
exemplos/      → códigos da aula (tipos, funções, classes)
exercicios/    → 10 exercícios de fixação
```

## Como rodar

```bash
# Exemplos
dart exemplos/00_primeiro_programa.dart
dart exemplos/exemplo_01_string.dart

# Exercícios
dart exercicios/exercicio_01_string.dart
dart exercicios/exercicio_10_desafio_completo.dart
```

Requer Flutter/Dart no PATH (`dart --version`).
